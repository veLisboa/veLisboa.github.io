# LinkedIn kit

- `Banner.jsx` — `Banner` (1584×396, full wordmark at 104px, 8px top rule, boxed monogram at right) and `ProfileTreatment` (400×400 monogram avatar + the photo crop rules).
- `Carousel.jsx` — `CoverSlide`, `ContentSlide`, `ClosingSlide` at 1080×1080. Cover and content on paper; closing inverted. Every non-closing slide carries the `Stamp` (plain monogram + n/total) on a hairline.
- `index.html` — tabbed viewer with a light/dark switch; frames are scaled with `transform` so the artwork stays at true export pixels.
