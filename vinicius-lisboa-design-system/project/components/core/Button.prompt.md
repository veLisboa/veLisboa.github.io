One-line: the system's only button — square corners, hairline border, no shadow; use for subscribe, download, contact.

```jsx
<Button>Assinar a newsletter</Button>
<Button variant="secondary" size="sm">Ver arquivo</Button>
```

Variants: primary (solid ink), secondary (hairline outline), ghost (text-only, for tertiary links in a row), accent (slate — once per view, never twice).
